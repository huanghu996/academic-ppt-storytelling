# From Audience Task to Presentation Design

Read during framing or when the same research must be presented to a different audience. This is a decision aid, not a claim that every discipline has one visual style.

## 1. Specify the intended change in understanding

Write: "The audience currently [knows or assumes X]. After the talk, they should be able to [explain, distinguish, evaluate, or decide Y], using [evidence]."

Choose a dominant task when several apply. A mixed audience may need a short conceptual setup before the same rigorous comparison, rather than a separate simplified conclusion.

| Audience task | Narrative priority | Visual form | Useful pacing or build |
|---|---|---|---|
| Recognize an unfamiliar problem | Concrete phenomenon, definition, consequence | An actual example with the relevant condition labeled | Establish context before a broad explanation |
| Understand a mechanism | Objects, relationships, dependencies, competing explanations | Stable diagram; distinct observed and hypothesized links | Change emphasis while preserving the overall structure |
| Judge an empirical improvement | Matched baseline, metric, variation, practical size | Paired comparisons, differences, intervals, failure cases | Show reading conditions before the central contrast |
| Follow a mathematical result | Definitions, assumptions, decisive inference | Aligned equations with explicit conditions | Reveal reasoning steps, retain dependencies |
| Assess a proposal | Testable hypothesis, discriminating observation, feasibility | Experimental design and decision table | Explain how both supporting and contrary outcomes are interpreted |
| Reconcile conflicting literature | Classify evidence and explain differences | Source-linked comparison matrix | Compare one methodological distinction at a time |
| Decide the next experiment | Residual uncertainty and value of a test | Competing explanations versus informative observations | End with a concrete decision and unresolved assumptions |

## 2. State a small design contract

Record the audience task, primary evidence form, main emphasis, and motion policy. For example:

> Specialists will assess a matched comparison. Use aligned field plots with a shared color scale and an adjacent difference profile. Keep geometry and normalization labels visible. Use static figures and one localized emphasis change; preserve a complete handout.

This contract should influence the actual pages. A claim-led deck with unrelated decorative imagery has not implemented it.

## 3. Keep context stable when interpretation depends on it

Stable context may include the current question, geometry, case, baseline, time, normalization, or evidence status. Put only the necessary labels near the figure. Keep label positions and object colors consistent between successive states.

Persistent context is an academic adaptation of a stateful interface. It should help the audience know what is being compared, without clocks, coordinates, decorative badges, or other irrelevant interface furniture.

For defense or seminar questions, a small optional path to backup evidence can be useful. Use links only where they save a real navigation problem, include a return link, and test both directions. The linear talk and static reading version must still stand alone.

## 4. Use contrast to explain, not to dramatize

Alternate conceptual setup with concrete evidence and interpretation. A dense result may be followed by a simpler statement of its consequence or boundary. Do not repeatedly switch backgrounds or layout systems merely to create variety.

One focal visual is a useful attention budget, not a rule that every talk has a single discovery. Let evidence determine emphasis. Do not delay the research question, hide caveats, or invent a surprising failure to create an opening hook.
